{% comment %} The Google Maps JavaScript API's loader: Google's dynamic library import snippet, as published, on the weekly (current) version. It defines google.maps.importLibrary and loads nothing until a map script calls it (js/leaflet.js L.Google.load, js/bs5/leafletGoogle.js loadGoogleMaps). Included by the event page in both template trees and by the event form. The key is restricted by referrer in Google's console. {% endcomment %}
